# Sternensammler

Ein ruhiges Browserspiel zum Einschlafen. Bewege den Korb und fange die herabschwebenden Sterntaler. Ist der Korb voll, werden sie zurück in die Welt ausgestreut.

- Desktop: Maus oder Pfeiltasten / A D — `Leertaste` streut früh aus, `P` pausiert, `M` stumm
- Mobil: Ziehen, um den Korb zu führen — Zwei-Finger-Tipp streut früh aus

## Entwicklung

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc --noEmit + Vite baut nach docs/
npm run preview
```

Siehe `CLAUDE.md` für die Architektur.
